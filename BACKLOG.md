# Skill backlog

Ideas for skills that don't exist yet. `skill-retro` adds lines here when a
task needed know-how no skill covered; `skill-gardener` grooms the list and
hands the top items to `skill-forge`.

Format: `- [ ] <proposed-name> — <what it would cover> (source: <project/task>, YYYY-MM-DD)`

## Candidates

- [ ] git-workflow — branch naming, commit message style, PR description and review etiquette shared across projects (source: scaffold, 2026-10-23)
- [ ] testing-strategy — what to unit vs. integration test in our stacks, fixtures, flaky-test triage (source: scaffold, 2026-10-23)
- [ ] debugging-playbook — reproduce → isolate → bisect → fix → regression test, with stack-specific tools (source: scaffold, 2026-10-23)
- [ ] code-review — checklist for reviewing PRs in our projects: correctness, security, migrations, observability (source: scaffold, 2026-10-23)
- [ ] release-and-deploy — versioning, changelog, deploy and rollback steps (source: scaffold, 2026-10-23)
- [ ] dependency-upgrades — safe upgrade procedure, reading changelogs, lockfile hygiene (source: scaffold, 2026-10-23)
